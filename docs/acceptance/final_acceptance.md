## 实际业务流程

- 教师真实接口组卷并向 STU001、STU002 发布同一份 4 题考试；两学生实际浏览器逐题作答、保存并确认交卷，均为 75/100。测试有意各错一题。
- 上传已有 UT Austin 英文期中卷：识别英语，解析 4 页、提取 8 题、生成 8 道中文译文和 4 页中文 PDF，2 题可发布，6 题因超出课程范围保留拓展状态。另有课件路径产生的 3 道衍生题；未将这些题冒称为原卷题。资料分类重新核对后为考试试卷。
- 学生 A 完成包含上述导入/衍生题的第二份试卷，50/50；两份试卷和复测共同进入多卷记录。导入、题库、考试、作答通过来源 ID、题目 ID、试卷 ID 和学生 ID 关联。
- 学生 A 从第一份考试发起复测：未获得合格的 AI 独立新题，转为题库备用；1 道未见题＋4 道重复题。实际浏览器提交 5/5，系统显示“练习完成”，当前薄弱点仍保留，未错误升级为知识点达标。
- 学生反馈与教师单卷、多卷、班级三种诊断的复测记录、知识点状态逐项一致。学生 B 访问 A 的反馈返回 403。
- 学生 B 从推荐资料实际点击课程原页，页面图片成功加载。未宣称所有外部网站正文均可读。

测试作答使用明确的验收输入，包括参考答案与刻意错答；没有直接写入分数、伪造评分成功或模拟接口响应。组卷、发布和导入是鉴权接口操作，登录、作答、提交、章节调整、资料阅读为真实浏览器操作。

## 限制和人工事项

1. 52 道原有题目、54 个历史题项、178 条评分记录仍缺可唯一确定的章节关联，不能宣称全库映射完成。题库提供人工章节调整；旧答卷需结合原课程资料核对后再执行有审计的历史关联修复。
2. 本轮真实复测验证的是题库备用与重复练习路径，没有新获得一次正式 AI 新题通过的证据；上一轮正式复测证据单独保留，未混作本轮结果。
3. 英文资料中 6 道超纲题不进入课程正式考试范围；生成内容仍需教师审阅。第二份试卷的满分只能证明测试评分流程，不是学习能力评估。
4. 外部平台可能登录或限流，本轮实际验证了课程原页阅读，未逐条重验全部外链。
5. 测试脚本可复核，但带写操作的脚本只应指向隔离数据。原有交付包不会自动包含本轮修改，应使用当前工作区与本验收数据。

## 复现

```powershell
$env:MLQ_DATA_DIR=(Join-Path (Get-Location) 'data/final-acceptance')
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8020
# 另一终端设置同一个 MLQ_DATA_DIR 后启动 worker
python -m backend.app.workers.worker --interval 2
# 只读复核
python backend/scripts/final_readback.py
```
