## 应用运行时提示词

模型适配器从本版开始保存真实请求messages、真实响应正文、模型名称、调用状态、时间及请求摘要，数据存入model_calls和prompt_records。失败调用保存实际请求与空响应，并保留调用错误状态。API密钥、授权字段、密码及已知密钥会脱敏，内嵌图片用摘要代替。

教师端“题库与组卷”中的“导出运行提示词”下载JSON；对应接口为 GET /api/teacher/prompt-history/export。学生无权导出。尚未实际调用时返回空数组，这不代表已补齐课程要求的历史记录。

提示词模板在 backend/app/skills/prompts.py 及各实际模型调用服务中；模板只能说明系统如何构造请求，不能证明过去执行过。自动化测试中的TEST_DOUBLE_NOT_LIVE属于测试证据，不是课堂真实模型使用记录。
