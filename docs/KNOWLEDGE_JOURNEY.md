# 知识点地图与学习证据时间线

入口在学生端的学习反馈。选择一份已完成原卷后，地图展示该原卷和关联复测涉及的知识点。默认使用地图，可切换原有列表。点击知识点后，右侧共享学习建议、课程资料、证据时间线、错题依据、概念自测和复测记录。

## 交互与数据口径

地图以已登记章节分组，原题项缺少章节时读取对应知识点的登记章节。仍无依据时显示章节待确认。搜索支持章节与概念名称，状态筛选支持需加强、证据不足、达标与延后确认。节点大小可调整，颜色与文字共同表达状态。当前选择写入链接，刷新可恢复对应概念。切换试卷后重置地图筛选。

状态直接来自原有feedback_workbench与learning_evidence判定。原卷全对、总分达到复测通过线、查看资源和阅读完成均不会单独提升掌握状态。地图采用章节归属关系，先修知识关系需教师提供后再扩展。

时间线展示真实原卷作答、每轮复测和实际记录的资源活动。默认最近记录在前，可切换发生顺序。缺少时间的记录单独放在末尾并明确标注。复测展示相关题目数量、待评分数量、独立性、题族与考查角度；旧记录缺失元数据时明确显示未记录。

资料预览自动保存首次查看时间，阅读完成由学生点击标记。活动使用现有LearningEvent表，按学生、原卷、知识点、资源和动作生成唯一ID，重复请求保持首次记录。收藏与阅读记录各自保存。活动不参与评分或掌握度计算。

## 接口与权限

GET /api/student/feedback/{attempt_id}继续返回原有字段，额外在diagnosis_workbench.concepts中提供map_chapter和timeline。

POST /api/student/learning-activity接受attempt_id、kp_id、resource_id及action。action限定resource_opened与resource_completed。服务检查已绑定学生身份、原卷所有权、提交及有效状态、知识点归属和资源关联。教师与其他学生无法代写学习记录。

实现主要位于learning_journey.py、KnowledgeMap.vue、LearningTimeline.vue及StudentFeedbackView.vue。无需数据库迁移或新增模型调用。当前范围为单名学生选定原卷及关联复测，跨卷全课程地图可在明确聚合规则后扩展。
