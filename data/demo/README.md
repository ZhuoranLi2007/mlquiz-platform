# 演示数据包

`mlquiz-course-demo.sqlite3.gz` 是从本地课程数据库生成的脱敏快照。

- 保留：匿名学生编号、题库、考试、作答、评分、已完成重评分运行标记、诊断、60份文档元数据、
  4612个课程检索片段、4份教学资源、参考答案PDF、在线资源封面、必要页图和已校验的历史原题清单。
- 删除：密码哈希、登录会话、API密钥、模型与后台任务日志、学生手写附件。
- `assets/` 只包含活跃页面实际引用的原件、封面和页图，不包含完整的
  267MB课程资料归档目录，也不包含约100MB的源DOCX。

首次执行根目录的 `start.ps1` 时，数据会恢复到 `data/db/`，并在
`data/private/` 生成只供本机快速登录使用的学生密码。两个目录均不会提交到Git。
